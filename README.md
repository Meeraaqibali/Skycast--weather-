# 🌤️ SkyCast Weather

A premium Flutter weather app with beautiful design, multi-language support, and offline-friendly caching.

## ✨ Features

- 🌍 **Global city search** with smart matching (prioritizes Pakistan cities)
- 🌡️ **Real-time weather** from Open-Meteo API (free, no API key needed)
- 📅 **7-day forecast** with expandable view (More/Less)
- ⏰ **24-hour forecast** with tappable hourly details
- 🌿 **Life Index** — advice for outdoor, clothing, health, driving
- 🌍 **Air Quality Index** with category explanations
- ☀️ **UV Index** tracking
- 💧 **Precipitation** and humidity details
- 🌅 **Sunrise / Sunset** times
- 🎨 **Beautiful minimal design** — pure black/white themes
- 🌓 **Auto / Light / Dark** theme modes
- 🌐 **Multi-language** — English, Urdu (اردو), Sindhi (سنڌي), Español
- 📏 **Text size setting** — Small / Medium / Large / Extra Large
- ⚡ **Animated weather icons** — spinning sun, jiggling clouds, bobbing rain, flashing storms
- 🎬 **Smooth transitions** — splash, pages, sheets, dropdowns
- 📱 **Installs as APK** — native Android app

## 📱 Installation

### Method 1: Download APK
1. Go to [Releases](../../releases/latest)
2. Download `app-release.apk`
3. Enable "Install from unknown sources"
4. Tap to install

### Method 2: Build from source
1. Clone the repo
2. Push to `main` — GitHub Actions builds APK automatically
3. Download from the Actions tab

## 🛠️ Tech Stack

- **Framework:** Flutter 3.19
- **API:** [Open-Meteo](https://open-meteo.com/) (weather + geocoding + air quality)
- **Storage:** SharedPreferences (settings persistence)
- **Build:** GitHub Actions (auto-builds APK on push)
- **Language:** Dart
